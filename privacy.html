AutoTube privacy policy

Last updated: 17 November 2026.

AutoTube is a personal tool used by one person to manage their own YouTube channel. This policy describes what the tool does with data it receives from Google.

What AutoTube accesses

With the owner's permission (the YouTube scope "manage your YouTube account"), AutoTube uses the YouTube Data API to upload the owner's videos, set their titles, descriptions, thumbnails and release times, read the status of those videos and of the owner's channel, and post comments on the owner's own videos.

What AutoTube stores

The sign-in token that Google issues is stored only on the owner's own computer, in a file readable only by the owner. AutoTube has no server and no database in the cloud. It does not copy YouTube data anywhere else.

What AutoTube shares

Nothing. AutoTube does not sell, share, transfer or disclose data received from Google to anyone. It uses no advertising and no analytics, and it does not use the data for any purpose other than the uploading and channel management described above.

Google API Services User Data Policy

AutoTube's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Withdrawing access

The owner can remove AutoTube's access at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends access.

Contact

Questions can be sent through the channel's YouTube page.
